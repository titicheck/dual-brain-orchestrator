# 01: Living Memory Window Synchronization CLI

**What to build:** A standalone, zero-dependency Python 3 standard-library command-line utility (`check-origin`, `sync`, `bind`, `reset`) and `unittest` black-box replay suite (`Seam 1`) that verifies session origin read-only on compaction boundaries, deterministically extracts, UTF-8-paginates, fingerprints, and two-phase commits an Antigravity `Trunk Session`'s compaction-bounded `Living Memory Window` into a session-isolated scratch directory so an `Execution Subagent` inherits clean context on spawn, receives lossless incremental deltas on continuation, and automatically rotates cleanly on compaction, conversation rewind, or execution-tier change without losing prior `<report>` history.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Implements `check-origin --transcript <path>` mutating zero files on disk and printing `{"origin": "TRUNK" | "SUBAGENT" | "UNKNOWN"}` from folded `step 0` (`USER_INPUT` vs `SYSTEM_MESSAGE` vs empty or missing transcript), plus `sync --transcript <path> --state-dir <dir> [--tier <tier>]` validating `--tier` against `{"flash", "pro", "flash_lite", "inherit"}` and overriding CLI parser errors to exit `1` (`0` success; `1` invalid arguments, invalid tier, empty subagent ID, invalid JSON state, or `bind` with `pending_sync` null; `2` missing logs parent directory, unreadable log, mid-file corrupt JSONL, or missing non-boolean integer `step_index`, ignoring only a partial trailing non-empty EOF line), emitting clean Turn-1 `SPAWN_NEW` (`-1` sentinels, `prefix_digest: ""`, `delta_empty: true`, staging `pending_sync` and clearing stale pages) when the logs directory exists but the transcript is absent or 0 bytes.
- [ ] Folds append-only JSONL records by canonical integer `step_index` (later record at `k` invalidates earlier records at `>= k`) and enforces the `step 0` backstop returning `{"action": "SKIP_SUBAGENT_SESSION", ...}` with exit `0` and zero state mutation whenever folded `step 0` has `type == "SYSTEM_MESSAGE"`.
- [ ] Computes `prefix_digest` over `[max(0, latest_checkpoint_step) .. last_synced_step]` **before** full-log expansion and **independently of `execution_subagent_ids`** (`sha256` hex of canonical JSON over `[step_index, type, created_at, content_or_empty]` tuples, short-circuiting to `""` when `last_synced_step < window_start`), expands retained `"truncated_fields": ["content"]` from sibling companion full logs **prior** to extraction (verifying `(step_index, type)` at 0-based line index first, then last `(step_index, type)`, gracefully keeping compact content if missing), and extracts within `[window_start .. max_folded_step]`: `CHECKPOINT` summaries; `USER_INPUT` unwrapped at outermost `<USER_REQUEST>` after stripping external metadata tags and skipping blank text; `PLANNER_RESPONSE` replies with non-empty `content.strip()`; and `[Message] ... sender=<id>` from `SYSTEM_MESSAGE` or `EPHEMERAL_MESSAGE` anchored on the outer header line when `<id>` is in append-only `execution_subagent_ids` (extracting outermost `<report>...</report>`, falling back to the outer `[Message]` body if untagged).
- [ ] Clears stale exported pages per sync and renders sequential Markdown pages with fixed-width total-page-independent headers strictly `< 40,000` UTF-8 bytes **total including headers and separators** (`len(rendered) < 40000`), splitting progressively on message boundaries, line boundaries, and valid UTF-8 code-point boundaries.
- [ ] Persists `{ bound_subagent_id, bound_tier, execution_subagent_ids, checkpoint_step, last_synced_step, prefix_digest, pending_sync }` with symmetric two-phase `pending_sync` -> `bind` commit on both `SPAWN_NEW` (`bound_subagent_id` null, `latest_checkpoint_step != checkpoint_step`, `max_folded_step < last_synced_step`, intra-epoch `prefix_digest` mismatch, or `tier != bound_tier`) and `RESUME_EXISTING` (`delta_empty: true` when empty); `bind` commits `pending_sync` and appends `<id>` to `execution_subagent_ids`; default `reset --state-dir <dir>` resets binding and watermarks while **preserving `execution_subagent_ids`** unless `--purge` is passed.
- [ ] Passes a zero-dependency Python `unittest` subprocess suite (`Seam 1`) covering Turn-1 empty or missing transcript `SPAWN_NEW` -> `bind` -> Turn-2 `RESUME_EXISTING` (`last_synced_step == -1`), read-only `check-origin`, `SKIP_SUBAGENT_SESSION`, **post-compaction and partial-rewind `prefix_digest` stability across `bind`**, `reset` preserving `execution_subagent_ids` vs `reset --purge`, companion `(step_index, type)` line verification + missing fallback, outermost `<USER_REQUEST>` and `<report>` extraction + untagged bound-sender fallback + spoofed inner header rejection, fixed-width header `< 40,000`-byte multi-byte splits + stale cleanup, `--tier` validation, and exit `1` vs `2` error cases.
