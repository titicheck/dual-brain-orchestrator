# 01: Living Memory Window Synchronization CLI

**What to build:** A standalone, zero-dependency Python 3 standard-library command-line utility (`sync`, `bind`, `reset`) and `unittest` black-box replay suite (`Seam 1`) that deterministically extracts, UTF-8-paginates, fingerprints, and two-phase commits an Antigravity `Trunk Session`'s compaction-bounded `Living Memory Window` into a session-isolated scratch directory so an `Execution Subagent` inherits clean context on spawn, receives lossless incremental deltas on continuation, and automatically rotates on compaction, conversation rewind, or execution-tier change.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Implements `sync --transcript <path> --state-dir <dir> [--tier <str>]` (default `--tier flash`) overriding CLI argument parsing errors to exit `1` (exit codes: `0` success, `1` invalid arguments or invalid state, `2` missing parent logs directory or unreadable or corrupt mid-file JSONL), gracefully emitting clean initial `SPAWN_NEW` (`-1` sentinels, `delta_empty: true`) on Turn 1 when the logs directory exists but the transcript is absent or 0 bytes.
- [ ] Folds append-only JSONL records by canonical integer `step_index` (later record at `k` invalidates earlier records at `>= k`, skipping incomplete trailing EOF lines) and enforces the hard `step 0` backstop returning `{"action": "SKIP_SUBAGENT_SESSION", ...}` with exit `0` and zero state mutation whenever folded `step 0` has `type == "SYSTEM_MESSAGE"`.
- [ ] Resolves truncated `"content"` fields from the fixed sibling companion full-log file **prior** to extraction (matching 0-based line index first, then last `(step_index, type)`, gracefully keeping compact content if the companion file is absent), and positively extracts within `[max(0, latest_checkpoint_step) .. max_folded_step]` (`-1` no-checkpoint sentinel): `CHECKPOINT` summaries; `USER_INPUT` stripped of `<ADDITIONAL_METADATA>` and `<USER_SETTINGS_CHANGE>` and unwrapped at the **outermost** `<USER_REQUEST>` envelope; non-empty `PLANNER_RESPONSE` replies; and `<report>...</report>` blocks from `SYSTEM_MESSAGE` or `EPHEMERAL_MESSAGE` strictly when `sender=<id>` matches an ID in `state.execution_subagent_ids`.
- [ ] Clears stale exported pages per sync and renders sequential Markdown page files strictly `< 40,000` UTF-8 bytes **total including page headers and separators** (`len(rendered) < 40000`), splitting progressively on message boundaries, line boundaries, and valid UTF-8 code-point boundaries for oversized lines.
- [ ] Implements symmetric two-phase watermark persistence (`{ bound_subagent_id, bound_tier, execution_subagent_ids, checkpoint_step, last_synced_step, prefix_digest, pending_sync }`): `sync` stages `pending_sync` without advancing active watermarks on **both** `SPAWN_NEW` (`bound_subagent_id` null, `checkpoint_step` changed, `max_folded_step < last_synced_step`, `sha256` canonical `(step_index, type, extracted_text)` `prefix_digest` mismatch, `bound_subagent_id` missing from folded `GENERIC` and `SYSTEM_MESSAGE` records, or `tier != bound_tier`) and `RESUME_EXISTING` (`delta_empty: true` when empty); `bind --state-dir <dir> --subagent-id <id>` commits `pending_sync` after dispatch succeeds (updating `execution_subagent_ids`, resetting the list on rewind or compaction, failing `1` if `pending_sync` is null); and idempotent `reset --state-dir <dir>` clears state and pages cleanly.
- [ ] Passes a zero-dependency Python `unittest` subprocess suite (`Seam 1`) covering Turn-1 empty/missing transcript `SPAWN_NEW`, hard `step 0` `SKIP_SUBAGENT_SESSION`, symmetric two-phase `RESUME_EXISTING` delta commit (verifying un-bound sync retains undelivered steps), `execution_subagent_ids` `<report>` sender isolation across tier rotations, pre-extraction companion full-log resolution + missing-companion graceful fallback, intra-epoch `prefix_digest` and post-flush vanished-subagent rewind rotation, outermost `<USER_REQUEST>` unwrap with embedded literal closing tags, total rendered page `< 40,000`-byte multi-byte splitting + stale-page cleanup, `tier != bound_tier` rotation, idempotent `reset`, `CHECKPOINT` rotation, and exit `1` vs `2` error cases.
