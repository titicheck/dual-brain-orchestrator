# 01: Living Memory Window Synchronization CLI

**What to build:** A standalone, zero-dependency Python 3 standard-library command-line utility (`check-origin`, `sync`, `bind`, `reset`) and `unittest` black-box replay suite (`Seam 1`) that enforces strict pre-mutation validation, verifies session origin read-only on compaction boundaries, deterministically extracts, LF UTF-8-paginates (within both `< 40,000` bytes and `<= 750` lines), fingerprints, quarantines post-rotation orphaned `<report>`s, and atomically two-phase commits an Antigravity `Trunk Session`'s compaction-bounded `Living Memory Window` into a session-isolated scratch directory.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Implements read-only `check-origin --transcript <path>` mutating zero files on disk and printing `{"origin": "TRUNK" | "SUBAGENT" | "UNKNOWN"}` via `.get(0)` over folded `step 0` (`SYSTEM_MESSAGE`, or `USER_INPUT` whose unwrapped and trimmed prompt begins with `[swarm]`, `[board]`, or `[EXECUTION SUBAGENT — SINGLE PHASE]` -> `"SUBAGENT"`, all other `USER_INPUT` -> `"TRUNK"`, absent file, empty transcript, or missing step 0 -> `"UNKNOWN"`), plus `sync --transcript <path> --state-dir <dir> [--tier <tier>]` overriding CLI parser errors to exit `1` (`0` success; `1` invalid arguments, invalid `--tier`, empty or whitespace `--subagent-id`, corrupt, non-dict, or schema-invalid JSON state, or `bind` with `pending_sync` null; `2` missing logs location on uninitialized non-standard paths, unreadable log, mid-file corrupt or non-dict JSONL or missing or non-string `type` or non-list `truncated_fields` in primary or companion logs, or missing, non-int, boolean, or `< 0` `step_index`, ignoring only an incomplete final non-empty EOF line failing JSON parse while accepting valid final JSON lines without trailing newline).
- [ ] Enforces strict pre-mutation validation in `sync` (argument checks, schema validation of existing session state, logs path validation, primary transcript folding by canonical integer `step_index >= 0` where later record `k` invalidates earlier `>= k` and tracks primary 0-based line indices, and `.get(0)` `SKIP_SUBAGENT_SESSION` backstop returning full 8-field JSON with exit `0` whenever `step 0` classifies as `"SUBAGENT"`) **before** creating `--state-dir`, clearing stale exported pages, or staging atomic `pending_sync`; on Turn-1 empty grace (missing transcript under an existing parent logs directory or valid `<Artifact Directory Path>` logs tail, `0` bytes, or zero folded records), preserves `execution_subagent_ids` and `retired_subagent_max_step`, clears stale pages, stages atomic `pending_sync`, and emits clean 8-field `SPAWN_NEW` (`-1` sentinels, `prefix_digest: ""`, `delta_empty: true`).
- [ ] Computes `compute_digest(folded, window_start, upto_step)` **before** companion expansion in **ascending `step_index` order** and **independently of `execution_subagent_ids` and `retired_subagent_max_step`** (`sha256` hex of canonical UTF-8 JSON over `[step_index, type, created_at_str_or_empty, raw_content_str_or_empty]`, returning `""` when `upto_step < window_start` or empty)—using `upto_step = state.last_synced_step` for rewind verification and `upto_step = max_folded_step` for `pending_sync.prefix_digest` and stdout—then loads and **folds sibling companion full-log by `step_index` (`later k invalidates >= k`)** within `[window_start .. max_folded_step]` (verifying primary 0-based line index was not invalidated and matches `(step_index, type)` with string `content` before folded `(step_index, type)` fallback, or gracefully keeping compact `content` when absent) **prior** to evaluating the Turn-1 empty-grace post-dispatch rewind guard (`bound_subagent_id` in expanded `GENERIC`, `SYSTEM_MESSAGE`, `EPHEMERAL_MESSAGE` string `content` or serialized `PLANNER_RESPONSE` `tool_calls`, else `SPAWN_NEW`).
- [ ] Extracts within `[window_start .. max_folded_step]`: non-empty `CHECKPOINT` (`content.strip()`) and `PLANNER_RESPONSE` (`content.strip()`); boundary-only `USER_INPUT` normalizing CRLF to LF, discarding outer `<USER_SETTINGS_CHANGE>...</USER_SETTINGS_CHANGE>` envelopes and `<ADDITIONAL_METADATA>` outer tags from leading and trailing boundaries only, stripping `The current local time is:` lines while retaining non-whitespace metadata lines (`@[ITEM]` mention blocks and uploaded attachment descriptors), unwrapping outermost `<USER_REQUEST>...</USER_REQUEST>` only when enclosing the trimmed core, joining non-empty core and preserved metadata with `"\n\n"`, and skipping empty prompts; and strict one-pass outer-envelope `SYSTEM_MESSAGE` or `EPHEMERAL_MESSAGE` normalizing CRLF to LF and inspecting **exclusively** the single outermost `[Message]` candidate (trimmed start, immediately after opening `<SYSTEM_MESSAGE>\n`, or immediately after the first standalone `\n<SYSTEM_MESSAGE>\n` preceded by zero `\n[Message] ` lines—never scanning deeper) requiring `<id>` in `execution_subagent_ids` and (`<id> == bound_subagent_id` or `step_index <= retired_subagent_max_step.get(<id>, step_index)`), stripping trailing `</SYSTEM_MESSAGE>`, retaining `<report>...</report>` tags when extracted, or keeping non-empty `content=` fallback body.
- [ ] Clears stale exported pages per sync after validation passes; sets `delta_empty: true, pages: []` if zero blocks extract while still staging atomic `pending_sync`; formats canonical LF-only UTF-8 Markdown pages (`# Living Memory Window — Page 001\n\n` plus `## [Step <N>] <Checkpoint Summary | User | Planner | Execution Report>` with `(cont.)` on split blocks and `"\n\n---\n\n"` separators, resolved absolute paths in `"pages"`) whose **exact rendered size including actual header width and separators** satisfies **both** `len(rendered_bytes) < 40000` and `line_count <= 750` via message, line, and valid UTF-8 code-point splits; commits atomically via `os.replace` on `bind` (recording `retired_subagent_max_step[prev_id] = pending_sync.synced_through` when replacing a different prior bound ID); preserves both allowlist and retirement map on default `reset`; and deletes state unconditionally on `reset --purge`.
- [ ] Passes a zero-dependency Python `unittest` subprocess suite (`Seam 1`) covering missing `<Artifact Directory Path>` vs uninitialized logs tail vs non-existent parent dir, 0-byte, partial EOF, and no-newline valid EOF Turn-1 `SPAWN_NEW` -> `bind` -> Turn-2 `RESUME_EXISTING`, Turn-1 empty-grace post-dispatch rewind after companion expansion (`GENERIC` and `PLANNER_RESPONSE` `tool_calls`), read-only `check-origin` (including `[swarm]`/`[board]` `step 0`), pre-mutation `SKIP_SUBAGENT_SESSION`, ascending `compute_digest` stability across `bind` and compaction and folded companion rewind rejection, `retired_subagent_max_step` quarantining late orphaned `<report>`s + `reset` vs `reset --purge` + schema-invalid state exit `1`, boundary-only CRLF `USER_INPUT` preserving interior literal tags + `@[ITEM]` + image-only `<USER_REQUEST>` + outer one-pass `SYSTEM_MESSAGE` index-0 and verbatim prose preamble + retained `<report>` tags + untagged `content=` fallback + spoofed inner `[Message]` rejection inside `Isolated Subagent` or background-task records, `delta_empty`, dual-cap (`< 40,000` bytes and `<= 750` lines) LF-only disk verification, `tier != bound_tier` rotation, invalid args or empty-or-whitespace IDs exiting `1`, and malformed or non-dict JSONL or missing `type` or non-list `truncated_fields` exiting `2`.
