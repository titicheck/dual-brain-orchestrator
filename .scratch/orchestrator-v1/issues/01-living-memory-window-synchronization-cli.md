# 01: Living Memory Window Synchronization CLI

**What to build:** A standalone, zero-dependency Python 3 standard-library command-line utility (`check-origin`, `sync`, `bind`, `reset`) and `unittest` black-box replay suite (`Seam 1`) that verifies session origin read-only on compaction boundaries, deterministically extracts, UTF-8-paginates, fingerprints, and two-phase commits an Antigravity `Trunk Session`'s compaction-bounded `Living Memory Window` into a session-isolated scratch directory so an `Execution Subagent` inherits clean context on spawn, receives lossless incremental deltas on continuation, and automatically rotates cleanly on compaction, conversation rewind, or execution-tier change without losing prior `<report>` history.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Implements read-only `check-origin --transcript <path>` mutating zero files on disk and printing `{"origin": "TRUNK" | "SUBAGENT" | "UNKNOWN"}` via `.get(0)` over folded `step 0` (`USER_INPUT` vs `SYSTEM_MESSAGE` vs empty or missing step 0), plus `sync --transcript <path> --state-dir <dir> [--tier <tier>]` validating `--tier` against `{"flash", "pro", "flash_lite", "inherit"}` and overriding CLI parser errors to exit `1` (`0` success; `1` invalid arguments, invalid tier, empty subagent ID, corrupt JSON state, or `bind` with `pending_sync` null; `2` missing logs parent directory, unreadable log, mid-file corrupt JSONL in primary or companion logs, or missing, non-int, boolean, or `< 0` `step_index`, ignoring only an incomplete trailing non-empty EOF line), emitting clean 8-field Turn-1 `SPAWN_NEW` (`-1` sentinels, `prefix_digest: ""`, `delta_empty: true`, staging `pending_sync` and clearing stale pages) whenever the transcript is absent, `0` bytes, or yields zero folded records after ignoring a trailing partial EOF line.
- [ ] Folds append-only JSONL records by canonical integer `step_index >= 0` (tracking each folded record's original 0-based JSONL line index in the primary transcript; later record at `k` invalidates earlier records at `>= k`) and enforces the `.get(0)` backstop returning full 8-field `SKIP_SUBAGENT_SESSION` (`{"action": "SKIP_SUBAGENT_SESSION", "tier": tier, "subagent_id": null, "checkpoint_step": -1, "synced_through": -1, "prefix_digest": "", "delta_empty": true, "pages": []}`) with exit `0` and zero state mutation whenever folded `step 0` has `type == "SYSTEM_MESSAGE"`.
- [ ] Defines `compute_digest(folded, window_start, upto_step)` **before** companion expansion and **independently of `execution_subagent_ids`** (`sha256` hex of canonical JSON preserving non-ASCII UTF-8 over `[step_index, type, created_at_str_or_empty, raw_content_str_or_empty]`, returning `""` when `upto_step < window_start` or empty)—using `upto_step = state.last_synced_step` for rewind verification and `upto_step = max_folded_step` for `pending_sync.prefix_digest` and stdout—and checks that after a Turn-1 empty-grace `bind` (`last_synced_step == -1`, non-empty `folded`), `bound_subagent_id` appears in at least one folded `GENERIC`, `SYSTEM_MESSAGE`, or `EPHEMERAL_MESSAGE` string `content` in `[window_start .. max_folded_step]` (else `SPAWN_NEW`).
- [ ] Expands retained `"truncated_fields": ["content"]` within `[window_start .. max_folded_step]` from the sibling companion full-log file **prior** to extraction (checking **that retained record's 0-based JSONL line index in the primary transcript** first with `(step_index, type)` and `isinstance(content, str)` verification before `(step_index, type)` fallback, gracefully keeping compact content if absent), and extracts within `[window_start .. max_folded_step]`: `CHECKPOINT` summaries; `USER_INPUT` stripping outer `<USER_SETTINGS_CHANGE>...</USER_SETTINGS_CHANGE>` envelopes outside `<USER_REQUEST>` completely and stripping only `The current local time is:` lines inside outer `<ADDITIONAL_METADATA>...</ADDITIONAL_METADATA>` envelopes outside `<USER_REQUEST>` while preserving any remaining non-whitespace metadata lines (resolved `@[ITEM]` mention blocks and user-uploaded attachment descriptors), unwrapping outermost `<USER_REQUEST>...</USER_REQUEST>` (`close_idx > open_idx`), appending preserved non-timestamp metadata (`"\n\n"`-joined when both are non-empty), and skipping only when empty or whitespace-only; `PLANNER_RESPONSE` replies with non-empty `content.strip()`; and `[Message] timestamp=<non-ws> sender=<id> priority=<non-ws> content=<body...>` on `SYSTEM_MESSAGE` or `EPHEMERAL_MESSAGE` anchored either at `content.lstrip()` start or immediately on the line after a standalone `<SYSTEM_MESSAGE>` tag line (`\n<SYSTEM_MESSAGE>\n[Message] `, never matching Antigravity's inline prose `<SYSTEM_MESSAGE>` token) when `<id>` is in append-only `execution_subagent_ids` (extracting outermost `<report>...</report>`, or untagged `content=` slice stripped of `</SYSTEM_MESSAGE>`).
- [ ] Clears stale exported pages per sync; sets `delta_empty: true, pages: []` if zero blocks extract (still staging `pending_sync`); renders `# Living Memory Window — Page 001` sequential Markdown pages whose **exact rendered size including actual header width and separators** is `< 40,000` UTF-8 bytes (`len(rendered) < 40000`) via message, line, and code-point splits; commits both `SPAWN_NEW` and `RESUME_EXISTING` symmetrically via `pending_sync` -> `bind`; and keeps default `reset` idempotent on missing state (exit `1` on corrupt JSON, preserving `execution_subagent_ids`) while `reset --purge` deletes state unconditionally.
- [ ] Passes a zero-dependency Python `unittest` subprocess suite (`Seam 1`) covering Turn-1 missing, 0-byte, and partial-EOF-only `SPAWN_NEW` -> `bind` -> Turn-2 `RESUME_EXISTING` (`last_synced_step == -1`), Turn-1 empty-grace post-dispatch rewind detection, read-only `check-origin`, 8-field `SKIP_SUBAGENT_SESSION`, non-empty Turn-1 `staged_digest` vs `verification_digest` across Turn 2 and compaction and rewind stability across `bind`, `reset` vs corrupt JSON exit `1` vs `--purge`, primary-line-index companion check after rewind + missing fallback, outer-stripped `<USER_REQUEST>` preserving non-timestamp outer `<ADDITIONAL_METADATA>` (`@[ITEM]` and uploaded attachment descriptors) + verbatim inline-tag prose preamble + standalone `<SYSTEM_MESSAGE>` `[Message]` line-anchored `<report>` + untagged `content=` body fallback + spoofed inner header rejection, zero-extract-block `delta_empty`, actual-header `< 40,000`-byte multi-byte splits + stale cleanup, `--tier` / `--subagent-id` / `ArgumentParser` exit `1`, and missing directory / `step_index < 0` / mid-file corrupt JSONL exit `2`.
