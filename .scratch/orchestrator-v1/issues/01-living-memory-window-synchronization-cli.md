# 01: Living Memory Window Synchronization CLI

**What to build:** A standalone, zero-dependency Python 3 standard-library command-line utility (`sync`, `bind`, `reset`) and `unittest` black-box replay suite (`Seam 1`) that deterministically extracts, UTF-8-paginates, fingerprints, and watermarks an Antigravity `Trunk Session`'s compaction-bounded `Living Memory Window` into a session-isolated scratch directory so an `Execution Subagent` inherits clean context on spawn, receives single-call incremental deltas on continuation, and automatically rotates on compaction, conversation rewind/edit, or execution-tier change.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Implements `sync --transcript <path> --state-dir <dir> [--tier <str>]` folding append-only JSONL records by canonical `step_index` (later record at `k` invalidates earlier records at `>= k`, ignoring partial trailing lines) and resolving the sibling companion full-log JSONL file only when `"content"` is listed in `truncated_fields` on a retained step (line-index match with `(step_index, type)` fallback and graceful degradation if absent).
- [ ] Extracts `[max(0, latest_checkpoint_step) .. max_step]` retaining `CHECKPOINT` summaries, `USER_INPUT` inner `<USER_REQUEST>` text stripped of `<ADDITIONAL_METADATA>` and `<USER_SETTINGS_CHANGE>`, non-empty `PLANNER_RESPONSE`/`MODEL` visible replies, and `<report>...</report>` blocks from `SYSTEM_MESSAGE`/`EPHEMERAL_MESSAGE`—strictly omitting `GENERIC` tool outputs, `Isolated Subagent` non-report messages, `[quota]`/`[swarm]` notices, and `thinking`.
- [ ] Clears stale pages per sync and splits output into sequential pages strictly `< 40,000` UTF-8 bytes (`len(b) < 40000`), preferring message boundaries, then line boundaries, and deterministically splitting oversized `>40,000`-byte unbroken lines on valid UTF-8 code-point boundaries.
- [ ] Tracks `{ bound_subagent_id, bound_tier, checkpoint_step, last_synced_step, prefix_digest, pending_sync }` in the session state JSON file: emits `SPAWN_NEW` whenever `bound_subagent_id` is null, `latest_checkpoint_step != checkpoint_step`, `max_step < last_synced_step`, folded prefix digest up to `last_synced_step` mismatches `prefix_digest`, or `tier != bound_tier` (committed via `bind --state-dir <dir> --subagent-id <id>`); otherwise advances watermarks directly in one `RESUME_EXISTING` call (`delta_empty: true` when empty) and supports `reset --state-dir <dir>` for dead-subagent recovery, returning deterministic single-line JSON and documented exit codes (`0`, `1`, `2`).
- [ ] Passes a zero-dependency Python `unittest` subprocess suite (`Seam 1`) covering initial `SPAWN_NEW` + `bind`, `<report>`-only system filtering, intra-epoch rewind/edit rotation via `prefix_digest`, `bound_tier` mismatch rotation, single `>40 KB` multi-byte UTF-8 line splitting + stale-page cleanup, `RESUME_EXISTING` delta and `delta_empty` elision, `reset` recovery, `CHECKPOINT` rotation, and error exit codes.
