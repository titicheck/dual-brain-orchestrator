# 02: Unified Orchestrator Skill and Official Two-Phase Execution Protocol

**What to build:** A self-contained `/orchestrator` skill module running one unified Official Orchestrator mode across shared-rule adoption and chat-bar invocation—encoding the centralized four-step Entry Gate (`Gate 0`–`Gate 3`) + post-Gate host tool check, canonical static scope-precedence tiering (`orchestrator-tier:`), Official Orchestrator's verbatim planning, execution entry, five-trigger hand-back, best-effort ~30-turn cadence, `[plan review]` gate, symmetric two-phase `Living Memory Window` dispatch, crash and interrupt recovery, parallel `Isolated Subagent` orthogonality, and clean separation of Antigravity runtime bindings from harness-neutral protocol rules.

**Blocked by:** 01: Living Memory Window Synchronization CLI

**Status:** ready-for-agent

- [ ] Configures non-spontaneous model-invocable skill frontmatter (omitting `disable-model-invocation: true` so shared or project agent rules can adopt `orchestrator`, while restricting the frontmatter description strictly to literal `/orchestrator` invocation or active Antigravity rule adoption without `"or names orchestrator"`) and enforces the ordered Entry Gate before checking host tools: Gate 0 Activation Authority (authorizing active Antigravity rule adoption, literal `/orchestrator` in the current or an earlier turn of the same conversation, or non-null `bound_subagent_id` covering `[Message]` wakeups with **no** literal `[plan review]` prefix), Gate 1 **unconditional** deference to exact lowercase `exit_plan_mode` or `enter_plan_mode` tools, Gate 2 silent deference to explicit `/swarm` and `[swarm]` or `[board]` turns, Gate 3 conversation-root (`step 0`) non-recursion (running read-only `check-origin` first on `<CONTEXT_SUMMARY>` or `# Resuming from a compaction` regardless of `[Message]` wakeups and failing closed on `SUBAGENT` or `UNKNOWN`, while uncompacted sessions yield only when root turn started with `[Message]`, `[swarm]`, `[board]`, or `[EXECUTION SUBAGENT — SINGLE PHASE]`), and Post-Gate Host Tool Verification halting cleanly with a one-line notice only if Antigravity tools are absent.
- [ ] Encodes verbatim Official Orchestrator `Trunk Session` Plan Mode rules: Prompt Precedence, Direct Answer Gate (pure questions, explanations, and zero-edit reviews stay in-session with zero CLI state writes), Approve-First Exception, and Depth Matching (1–2 sentence `<plan>...</plan>` only on settled `RESUME_EXISTING` follow-ups vs read-only investigation with non-mutating command flags and a complete, self-contained five-section `<plan>...</plan>` ending with `Re-plan if:` whenever `sync` emits `SPAWN_NEW` or on non-trivial work—keeping the verbatim Non-Override Safety Clause static inside every dispatch and continuation envelope).
- [ ] Enforces unified static scope-precedence tiering exclusively on the bound `Execution Subagent`: parses canonical `orchestrator-tier: <flash|pro|flash_lite|inherit>` rules (**project agent rules > shared engineering rules > built-in default `flash`**), passes `--tier <resolved_tier>` explicitly on every `sync` call, ignores conversational model mentions with zero separate manual-mode or dynamic chat-parameter switching, rotates cleanly via `tier != bound_tier` when project rules change, and resolves the CLI script from the loaded skill directory plus logs and state from `<Artifact Directory Path>` (`py -3` on Windows, `python3` on POSIX).
