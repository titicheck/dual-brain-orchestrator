# 02: Standalone On-Demand Orchestrator Skill and Two-Phase Execution Protocol

**What to build:** A self-contained `/orchestrator` skill module optimized for Antigravity single-model sessions—encoding a centralized four-step Entry Gate, single-unified-tier governance (`flash` default and locked unless `/orchestrator <tier>` is given), Official Orchestrator's verbatim 9-part planning, execution, five-trigger hand-back, ~30-turn review cadence, `[plan review]` gate, symmetric two-phase `Living Memory Window` dispatch, crash and interrupt recovery, parallel `Isolated Subagent` orthogonality, and a modular Harness Adapter Seam reserving non-normative stubs for future clients.

**Blocked by:** 01: Living Memory Window Synchronization CLI

**Status:** ready-for-agent

- [ ] Configures non-spontaneous model-invocable skill frontmatter (omitting `disable-model-invocation: true` so shared or workspace agent rules can adopt `orchestrator`, while restricting the frontmatter description strictly to literal `/orchestrator` invocation or active Antigravity rule adoption without `"or names orchestrator"`) and enforces the centralized four-step Entry Gate: Gate 0 Activation Authority, Gate 1 **unconditional** deference to exact lowercase `exit_plan_mode` or `enter_plan_mode` tools, Gate 2 silent deference on `/swarm` and standalone workflow skills, and Gate 3 Antigravity `step 0` non-recursion check across both prompt/compaction framing and CLI `SKIP_SUBAGENT_SESSION`.
- [ ] Encodes verbatim Official Orchestrator `Trunk Session` Plan Mode rules: Prompt Precedence, Direct Answer Gate (pure questions, explanations, and zero-edit reviews stay in-session), Approve-First Exception, and Depth Matching (1–2 sentence `<plan>` for settled follow-ups vs read-only investigation with non-mutating command flags and a complete five-section `<plan>...</plan>` ending with `Re-plan if:`—keeping the Non-Override Safety Clause static inside the execution envelope rather than generated inside each `<plan>`).
- [ ] Enforces the single unified tier rule exclusively on the bound `Execution Subagent`: defaults to and locks at `flash` (ignoring conversational model mentions), permitting `pro`, `flash_lite`, or `inherit` **only** via explicit `/orchestrator <tier>` scoped across that request's internal `[plan review]` continuations and rotating cleanly back to `flash` via `--tier` on the next new user turn; instructs runtime path resolution from `<Artifact Directory Path>` and skill-relative Python invocation (`py -3` on Windows, `python3` on POSIX).
- [ ] Encodes symmetric Antigravity dispatch and verbatim single-phase `Execution Subagent` rules (`[EXECUTION SUBAGENT — SINGLE PHASE]` header): `SPAWN_NEW` calls `invoke_subagent(Prompt=...)` + `bind` and yields turn immediately without polling; `RESUME_EXISTING` calls `send_message` + `bind` and yields; execution executes steps in order, handles minor mechanical deviations autonomously (1 retry before "failed twice"), self-counts ~30 LLM turns per dispatch for interim status `<report>`, stops immediately on all five Official early hand-back triggers verbatim (`Re-plan if:` included), and emits the five-part `<report>` reply.
- [ ] Encodes verbatim Official `[plan review]` rules, crash and mid-flight recovery, parallel `Isolated Subagent` orthogonality, and modular Harness Adapter Seam: treats `<report>` with Non-Override Safety Clause, enforces Review-Do-Not-Execute, applies the exact three-way exit, handles mid-flight interrupts via subagent listing (`kill` + `reset` + git inspection on redirect) and dead-subagent `send_message` failures via `reset` -> `sync` -> respawn (reporting quota or API aborts without silently switching models), leaves parallel `Isolated Subagents` untouched, and isolates Antigravity bindings cleanly behind a modular adapter interface with non-normative reserved stubs for Claude Code and Codex.
