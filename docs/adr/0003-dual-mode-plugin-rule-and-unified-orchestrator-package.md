# Dual-Mode Plugin Rule Activation, Global Flash Lock, and Unified Package Layout

To make the plugin toggle act as a drift-free global orchestration switch on Antigravity while preserving explicit on-demand control across standalone skill installations, we will ship both a thin always-on routing rule (`rules/AGENTS.md`) and a self-contained skill (`skills/orchestrator/SKILL.md`) under the unified identifier `orchestrator` (verified collision-free across built-in and user `~/.gemini` customizations). When enabled as a plugin (`plugin.json` at repository root alongside `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json`), `rules/AGENTS.md` activates global orchestration with the bound `Execution Subagent` strictly locked to the default `flash` execution tier—matching Official Orchestrator's fixed internal execution core and prohibiting conversational tier changes that could cause global execution drift—while disabling the plugin reduces context overhead to zero tokens (`agy-customizations/docs/plugins.md`). When invoked manually via `/orchestrator` (either in standalone skill installs or explicit per-turn invocation), execution defaults to `flash` and permits explicit execution-tier selection (such as `pro` or `flash_lite`) strictly scoped to that manually triggered invocation. All runtime assets (`SKILL.md`, `scripts/sync_memory.py`, `references/execution-protocol.md`, and `references/harnesses.md`) live inside `skills/orchestrator/` with zero `hooks.json` startup scripts or background sidecars.
