# Matt-Aligned Pure-Skill Plugin Packaging, Shared-Library Rule Adoption, and Fast-Tier Lock

To preserve clean user control across harnesses and decouple always-available manual invocation from global automatic orchestration, we reject bundling plugin-root `rules/AGENTS.md` (which Antigravity's plugin switch merges and unloads atomically alongside bundled skills while Claude Code and Codex do not auto-inject globally without hooks) and ship `orchestrator` under a Matt-aligned pure-skill layout with zero top-level `rules/` directory, zero `hooks.json` startup scripts, and zero persistent sidecars: `plugin.json` (`{"name": "orchestrator", "version": "1.0.0", "description": "...", "skills": ["./skills/orchestrator"]}`), `.claude-plugin/plugin.json` (`{"name": "orchestrator", "version": "1.0.0", "description": "...", "skills": ["./skills/orchestrator"]}`), `.claude-plugin/marketplace.json` (single-plugin marketplace manifest matching `mattpocock/skills`), `.codex-plugin/plugin.json` (`{"name": "orchestrator", "version": "1.0.0", "description": "...", "skills": "./skills"}`), `README.md`, self-contained skill module `skills/orchestrator/{SKILL.md, agents/openai.yaml, scripts/sync_memory.py, references/{execution-protocol.md, harnesses.md, rule-adoption.md}}`, and Python `unittest` suites `tests/{test_sync_memory.py, test_package_contracts.py, fixtures/}`. Across Antigravity, Claude Code, and Codex, `SKILL.md` omits `disable-model-invocation: true` (and `skills/orchestrator/agents/openai.yaml` omits `policy.allow_implicit_invocation: false`) so explicit shared-library or workspace rules can invoke the skill across harnesses, while `SKILL.md`'s frontmatter `description` strictly forbids spontaneous self-activation on ordinary prompts—limiting activation exclusively to explicit `/orchestrator` invocation or active `AGENTS.md` / `CLAUDE.md` rule adoption. Opting into **Rule-Driven Auto Mode** (via a shared-library `AGENTS.md` adoption-table row or `@[...]` file include referencing `skills/orchestrator/references/rule-adoption.md` `<24,000` bytes, or workspace `AGENTS.md` / `CLAUDE.md`) locks the bound `Execution Subagent` strictly to the fast execution tier (`"flash"` on Antigravity, `"sonnet"` on Claude Code, allowlisted fast model + `reasoning_effort: "medium"` on Codex) with conversational tier drift prohibited, whereas **Manual `/orchestrator` Mode** remains continuously reachable whenever the plugin or skill is installed, defaults to the fast execution tier, and permits explicit per-invocation tier overrides (`"pro"`, `"flash_lite"`, `"inherit"`, or harness equivalents).
