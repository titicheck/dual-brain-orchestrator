# Checkpoint-Bounded Living Memory Inheritance and Compaction-Synced Rotation

To give an Antigravity `Execution Subagent` the same living context as Official Orchestrator's shared-thread execution model without unbounded transcript growth or lossy manual summaries, a zero-dependency Python 3 standard-library CLI (`skills/orchestrator/scripts/sync_memory.py`, invoked via `py -3` on Windows or `python3` on POSIX relative to the loaded `SKILL.md` directory) resolves paths directly from `<Artifact Directory Path>` (`<appDataDir>/brain/<ConversationID>`)—reading `--transcript <Artifact Directory Path>/.system_generated/logs/transcript.jsonl` and writing session state into `--state-dir <Artifact Directory Path>/scratch/orchestrator`. CLI argument parsing overrides `ArgumentParser.error` to exit `1` (`0` = success, `1` = invalid arguments/tiers, empty `--subagent-id`, invalid JSON state, or `bind` when `pending_sync` is `null`, `2` = missing conversation logs parent directory, unreadable log, mid-file corrupt JSONL in primary or companion logs, or missing/non-int/bool/`< 0` `step_index`, ignoring only an incomplete final non-empty EOF line). It exposes four subcommands: `check-origin --transcript <path>` (read-only inspection mutating zero files on disk, emitting `{"origin": "TRUNK" | "SUBAGENT" | "UNKNOWN"}` via `.get(0)` over folded `step 0` `USER_INPUT` vs `SYSTEM_MESSAGE` vs empty), `sync --transcript <path> --state-dir <dir> [--tier <tier>]` (validating `--tier` against `{"flash", "pro", "flash_lite", "inherit"}`), `bind --state-dir <dir> --subagent-id <non_empty_id>`, and `reset --state-dir <dir> [--purge]`. Turn-1 empty grace fires whenever `--transcript` does not yet exist, is `0` bytes, or yields `not folded_records` after ignoring an incomplete trailing EOF line (clearing stale `pages/`, staging `pending_sync` in `state.json`, and emitting `{"action": "SPAWN_NEW", "tier": tier, "subagent_id": null, "checkpoint_step": -1, "synced_through": -1, "prefix_digest": "", "delta_empty": true, "pages": []}` so `bind` succeeds). Otherwise `sync` folds append-only records by canonical non-boolean integer `step_index >= 0` (later record at `k` invalidates earlier records at `>= k`), enforcing via `.get(0)` a hard backstop returning `{"action": "SKIP_SUBAGENT_SESSION", "tier": tier, "subagent_id": null, "checkpoint_step": -1, "synced_through": -1, "prefix_digest": "", "delta_empty": true, "pages": []}` with exit `0` and zero state mutation whenever folded `step 0` has `type == "SYSTEM_MESSAGE"`. Using `window_start = max(0, latest_checkpoint_step)` (where `latest_checkpoint_step` uses sentinel `-1` when no `CHECKPOINT` exists), define `compute_digest(folded, window_start, upto_step)` **before** `transcript_full.jsonl` expansion and **independently of `execution_subagent_ids`**, returning `""` if `upto_step < window_start` or the epoch slice is empty and otherwise `sha256` hex over `json.dumps([[r["step_index"], r["type"], r.get("created_at") if isinstance(r.get("created_at"), str) else "", r.get("content") if isinstance(r.get("content"), str) else ""] for r in folded if window_start <= r["step_index"] <= upto_step], separators=(",", ":"), ensure_ascii=False)` (non-ASCII UTF-8 preserved): rewind verification compares `compute_digest(folded, window_start, state.last_synced_step) != state.prefix_digest` when `state.last_synced_step >= window_start`, whereas `pending_sync.prefix_digest` and stdout `"prefix_digest"` always hold `compute_digest(folded, window_start, max_folded_step)`. When `state.bound_subagent_id` is non-null, `state.last_synced_step == -1`, and `folded` is now non-empty (following a Turn-1 empty-grace `bind`), `sync` emits `SPAWN_NEW` unless `state.bound_subagent_id` appears in at least one folded `GENERIC`, `SYSTEM_MESSAGE`, or `EPHEMERAL_MESSAGE` string `content` inside `[window_start .. max_folded_step]` (preventing a rewound Turn-1 empty-grace spawn from reusing the old subagent while allowing normal Turn-1 -> Turn-2 continuation once flushed). Retained steps within `[window_start .. max_folded_step]` whose `"truncated_fields"` includes `"content"` expand from fixed sibling `transcript_full.jsonl` (checking **that retained record's 0-based JSONL line index in the primary `transcript.jsonl`** first and verifying `(step_index, type)` equality and `isinstance(full_rec.get("content"), str)`, then falling back to the last matching `(step_index, type)` record, or gracefully keeping compact `content` if `transcript_full.jsonl` is absent). Within `[window_start .. max_folded_step]`, `sync` extracts `CHECKPOINT` string `content`; `USER_INPUT` with only outer leading/trailing `<ADDITIONAL_METADATA>` and `<USER_SETTINGS_CHANGE>` stripped outside `<USER_REQUEST>` before unwrapping outermost `<USER_REQUEST>...</USER_REQUEST>` (`close_idx > open_idx`, skipping empty/whitespace text); `PLANNER_RESPONSE` string `content` where `content.strip()` is non-empty (omitting `thinking`, `tool_calls`, `GENERIC`, `ERROR_MESSAGE`); and `SYSTEM_MESSAGE`/`EPHEMERAL_MESSAGE` allowing Antigravity's outer `"The following is a <SYSTEM_MESSAGE>...\n\n<SYSTEM_MESSAGE>\n"` preamble before `[Message] timestamp=... sender=<id> priority=... content=<body...>` **only** when `<id> in state.execution_subagent_ids` (extracting outermost `<report>...</report>` when `close_idx > open_idx`, or on untagged fallback taking the slice after `content=` on that outer `[Message]` header stripped of trailing `</SYSTEM_MESSAGE>`). On every `sync`, stale `<state-dir>/pages/page_*.md` files are cleared first; if extracted blocks are empty, `delta_empty` is `true` and `pages` is `[]` (still staging `pending_sync`); otherwise sequential Markdown pages (`# Living Memory Window — Page 001` fixed-width headers, measuring exact rendered UTF-8 bytes including actual header width `< 40000`) are written. `<state-dir>/state.json` persists `{ bound_subagent_id, bound_tier, execution_subagent_ids, checkpoint_step, last_synced_step, prefix_digest, pending_sync }`, where `execution_subagent_ids` is an **append-only allowlist**: both `SPAWN_NEW` (`bound_subagent_id` `null`, Turn-1 empty-grace `bound_subagent_id` missing once flushed, `latest_checkpoint_step != checkpoint_step`, `max_folded_step < last_synced_step`, verification `prefix_digest` mismatch, or `tier != bound_tier`) and `RESUME_EXISTING` stage `pending_sync`; `bind` commits `pending_sync` after `invoke_subagent`/`send_message` succeeds and appends `<id>`; default `reset` succeeds idempotently when `state.json` is absent, exits `1` on corrupt JSON state, and otherwise clears binding/watermarks while **preserving `execution_subagent_ids`** (`reset --purge` deletes `state.json` unconditionally). Empirical `L0-1` measurements (`44.1 KB` initial median, `4.3 KB` incremental median, `0%` `>45 KB` increments vs `211–818 KB` raw-tool bloat) confirm full intent preservation with compaction-synced rotation.
