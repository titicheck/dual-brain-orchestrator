# Checkpoint-Bounded Living Memory Inheritance and Compaction-Synced Rotation

## Context

An Antigravity `Execution Subagent` runs in its own native subagent conversation rather than sharing the parent thread. Without transferring the `Trunk Session`'s active context, the subagent loses conversational decisions and user constraints; conversely, dumping full raw transcripts including tool outputs bloats context (`211–818 KB` median/peak in `L0-1` vs Antigravity `read_file`'s `46,080`-byte / `800`-line read cap), and lossy LLM summaries violate lossless intent preservation.

Empirical `L0-1` and current-session trajectory measurements (`44.1 KB` initial median, `4.3 KB` incremental median, `0%` `> 45 KB` increments) confirm that projecting the host's compaction-bounded `Living Memory Window` cleanly preserves intent while synchronizing `Execution Subagent` lifetimes to host compaction epochs (augmented in `v1.2.0` by clock-free expected-cost `Execution Subagent` rotation when bloated child context outweighs fresh spawn cost).

## Decision

A zero-dependency Python 3 standard-library CLI (`skills/orchestrator/scripts/sync_memory.py`, invoked via `py -3` on Windows or `python3` on POSIX relative to the loaded `SKILL.md` directory) resolves paths directly from `<Artifact Directory Path>` (`<appDataDir>/brain/<ConversationID>`)—reading `--transcript <Artifact Directory Path>/.system_generated/logs/transcript.jsonl` (and sibling `transcript_full.jsonl`) and persisting session state under `--state-dir <Artifact Directory Path>/scratch/orchestrator`.

### Subcommands, Validation Order & Atomic Persistence
- **Exit codes & strict pre-mutation validation**: Overrides `ArgumentParser.error` so CLI argument/syntax errors exit `1` (`0` = success; `1` = invalid arguments, invalid `--tier` outside `{"flash", "pro", "flash_lite", "inherit"}`, empty/whitespace `--subagent-id`, corrupt/non-dict/schema-invalid `state.json`, or `bind` with `pending_sync: null`; `2` = `OSError` reading `state.json` or logs, `OSError` in `main`, missing `--transcript` logs directory on uninitialized non-standard paths during `sync`, mid-file invalid UTF-8, mid-file corrupt/non-dict JSONL or missing/non-string `"type"` or non-list `"truncated_fields"` in primary or companion logs, or missing/bool/non-int/`< 0` `step_index`). `fold_jsonl_file` reads raw bytes and decodes strictly as UTF-8 first (preserving valid trailing JSON lines without `\n`), dropping an incomplete trailing UTF-8 sequence only when `UnicodeDecodeError` occurs on a file not ending in `b"\n"`, and ignoring only a final non-empty EOF line failing `json.loads`. Both `state.json` schema validation and `transcript.jsonl` folding + `SKIP_SUBAGENT_SESSION` enforcement execute **before** creating `--state-dir`, clearing `pages/page_*.md`, or writing `state.json`. All `state.json` writes use an atomic temp file + `os.replace` (with 3-attempt `15ms` `PermissionError` retry) inside `--state-dir`, and all `state.json` and `pages/page_*.md` writes use UTF-8 with `newline="\n"` (`\r\n` and bare `\r` normalized to `\n` across all extracted block inputs).
- **`check-origin --transcript <path>`**: Read-only check mutating zero files on disk, emitting `{"origin": "TRUNK" | "SUBAGENT" | "UNKNOWN"}` (returns `{"origin": "UNKNOWN"}` with exit `0` whenever `--transcript` does not exist even if its parent directory is absent or `folded` is empty; exits `2` on unreadable or corrupt existing logs). `classify_origin(folded)` first scans retained `SYSTEM_MESSAGE` records via outermost envelope parsing for unspoofable swarm/fork markers (`"You are @"` + `"Everything before this turn is @"` on headerless outer `<SYSTEM_MESSAGE>`, or `[Message] ... content=` starting with `"You have just started. Your assignment (recorded on the board as #"`) -> `"SUBAGENT"`, then checks `folded[min(folded)]` (supporting UI-branched human chats starting at `step_index > 0`): requires `type == "USER_INPUT"` and `source in (None, "USER_EXPLICIT")`, strips leading `<USER_REQUEST>` + whitespace when `"content"` is in `truncated_fields`, rejects `[swarm]`/`[board]`/`[EXECUTION SUBAGENT — SINGLE PHASE]` prefixes -> `"SUBAGENT"`, and otherwise returns `"TRUNK"`.
- **`sync --transcript <path> --state-dir <dir> [--tier <tier>] [--force-spawn] [--subagent-transcript <path>]`**:
  - **Turn-1 Empty-Transcript Grace**: When `--transcript` does not yet exist (provided `transcript_path.resolve().parent` exists **or** `transcript_path.resolve().parts[-3:] == (".system_generated", "logs", "transcript.jsonl")` under an existing `<Artifact Directory Path>`), is `0` bytes, or yields zero folded records after ignoring an incomplete trailing EOF line (and existing `state.json`, if present, is valid JSON matching the schema), preserves existing `execution_subagent_ids`/`retired_subagent_max_step`, clears stale `pages/page_*.md`, stages `pending_sync`, and emits `SPAWN_NEW` with `-1` sentinels, `prefix_digest: ""`, `delta_empty: true`, and `pages: []`.
  - **Canonical Folding, Fail-Closed Origin Backstop, & `--force-spawn`**: Folds records by `step_index` (later record at `k` invalidates earlier records at `>= k`) and enforces `classify_origin(folded) != "TRUNK"` `SKIP_SUBAGENT_SESSION` (8-field JSON, exit `0`, zero disk writes). `--force-spawn` forces full-window `SPAWN_NEW` export for non-cancel respawns while preserving prior valid `<report>`s from `bound_subagent_id` up to `max_folded_step` until `bind` retires the old ID.
  - **Sender-Invariant `prefix_digest`**: With `window_start = max(0, latest_checkpoint_step)` (sentinel `-1` when no `CHECKPOINT`), `compute_digest(folded, window_start, upto_step)` runs **before** companion expansion in **ascending `step_index` order** independently of `execution_subagent_ids` and `retired_subagent_max_step`, hashing compact canonical UTF-8 JSON (`ensure_ascii=False`) over `[step_index, type, created_at_str_or_empty, raw_content_str_or_empty]`. Rewind verification compares `compute_digest(folded, window_start, state.last_synced_step) != state.prefix_digest` when `state.last_synced_step >= window_start`; `pending_sync.prefix_digest` and stdout `"prefix_digest"` always equal `compute_digest(folded, window_start, max_folded_step)`.
  - **Folded Companion Expansion, `C1` `RESUME_EXISTING`, & Clock-Free Expected-Cost `Execution Subagent` Rotation**: Computes `base_need_spawn` (`--force-spawn`, `bound_subagent_id is None`, epoch/watermark/digest mismatch, or `tier != bound_tier`) before companion loading. Only the `not base_need_spawn and last_synced_step == -1` branch expands all truncated types (including `GENERIC` `"content"` and `PLANNER_RESPONSE` `"tool_calls"`) across `[window_start .. max_folded_step]` for the Turn-1 Empty-Grace Rewind Guard (`turn1_bound_id_present`); `base_need_spawn` expands extractable types `"content"` across `[window_start .. max_folded_step]`; and candidate `RESUME_EXISTING` (`not base_need_spawn and last_synced_step >= 0`) expands extractable types `"content"` strictly at `step_index >= last_synced_step + 1` (preserving `C1` by skipping truncated `GENERIC` noise). Expansion loads and **folds sibling `transcript_full.jsonl` by `step_index` (`later k invalidates >= k`)**, resolving solely via `comp_folded.get(step_idx)` with `type` and `_created_at_compatible` enforced unconditionally (keeping compact fields if companion is absent).
  - **Pure `q=0` Expected-Cost `Execution Subagent` Rotation (`v1.2.0` / `v1.2.1`)**: On any non-`base_need_spawn` candidate `RESUME_EXISTING` (including Turn 2 following Turn-1 Empty-Grace `last_synced_step == -1` unified in `v1.2.1`), after computing delta bytes and estimating total active-epoch `est_lmw_bytes` (from optional `state.lmw_bytes`, `0` when `last_synced_step < window_start`, or seeded once in memory from `folded` on legacy `v1.1.x` state upgrades), `sync` checks the concurrent-writer guard (`last_bound_report_step > last_synced_step` via reverse scan of `folded`) and performs a fail-open `O(N)` reverse EOF byte scan (`CHILD_SCAN_CHUNK_BYTES = 65536`) of the bound child's `transcript.jsonl` (resolved cleanly via Antigravity sibling path or `--subagent-transcript`, never raising exit `1`/`2` on missing/shallow/unreadable child logs). Measuring `child_bytes_since_ckpt` from the latest valid `type == "CHECKPOINT"` line (inclusive, rejecting string-literal `"CHECKPOINT"` matches and invalid `step_index > eof_step_index`, with `A5` trailing EOF handling), `sync` flips `RESUME_EXISTING -> SPAWN_NEW` (reusing already-hydrated `delta_pages` when `slice_start == window_start` or running a second-pass companion expansion across `[window_start .. max_folded_step]` otherwise) whenever `0.60 * C_old > 1.55 * C_new + 15000` (`C_old = 35627 + 0.5703 * child_bytes_since_ckpt`, `C_new = 23730 + 0.4097 * est_lmw_bytes`). Wall-clock idle-TTL rotation and unconditional child-`CHECKPOINT` rotation remain rejected.

### Lossless Window Extraction, Retired-Subagent Quarantine & Dual-Cap Pagination
- **`USER_INPUT` Boundary-Only Parser**: Normalizes `\r\n` and bare `\r` to `\n`. Consumes outer metadata strictly from standalone tag lines (`line.strip(" \t") == open_tag` / `close_tag`) with balanced tag-depth scanning (`depth = 1`) from string boundaries (never scanning interior user prose or inline `@[...]` file literals): strips leading/trailing `<USER_SETTINGS_CHANGE>...</USER_SETTINGS_CHANGE>` envelopes; strips `<ADDITIONAL_METADATA>...</ADDITIONAL_METADATA>` outer tags from leading/trailing metadata blocks while removing lines whose `.strip()` starts with `The current local time is:` and preserving remaining non-whitespace lines (resolved `@[ITEM]` mentions, uploaded attachment paths); only when the remaining trimmed core begins with `<USER_REQUEST>` and ends with `</USER_REQUEST>`, unwraps those outermost `<USER_REQUEST>` tags; joins `.strip()`-non-empty core and preserved metadata with `"\n\n"`; and skips empty/whitespace results.
- **`SYSTEM_MESSAGE` / `EPHEMERAL_MESSAGE` One-Pass Outer-Envelope Parser**: Normalizes `\r\n` to `\n` and inspects `s = content.lstrip(" \t\n")`. Accepts **exclusively** the single outer header candidate—`s` itself if `s.startswith("[Message] ")`, the line immediately after opening `<SYSTEM_MESSAGE>\n` if `s.startswith("<SYSTEM_MESSAGE>\n")`, or (only when `s` starts with neither) the single line immediately following the first standalone `\n<SYSTEM_MESSAGE>\n` line **provided** `s` starts with Antigravity's prose preamble (`s.startswith("The following is a <SYSTEM_MESSAGE>")`) followed solely by that single preamble line plus optional blank lines before that `<SYSTEM_MESSAGE>` tag line (blocking unwrapped task/error preambles and spoofed inner `[Message]` lines). Accepts records only when `<id> in state.execution_subagent_ids` **and** (`<id> == state.bound_subagent_id` or `step_index <= state.retired_subagent_max_step.get(<id>, step_index)`). Trims trailing `</SYSTEM_MESSAGE>` via `.rstrip()`, at most one `.removesuffix("</SYSTEM_MESSAGE>")`, and `.strip()`; extracts outermost `<report>...</report>` **retaining `<report>` tags** when `close_idx > open_idx`, or falls back to `.strip()`-non-empty `content=` text.
- **Other Records & Dual Page Cap**: Extracts CRLF-normalized, non-empty `CHECKPOINT` (`content.strip()`) and `PLANNER_RESPONSE` (`content.strip()`), ignoring `thinking`, `tool_calls`, `GENERIC`, and `ERROR_MESSAGE`. Clears stale `pages/page_*.md` only after validation and `SKIP_SUBAGENT_SESSION` pass. Renders `pages/page_001.md`, ... (absolute `.resolve()` paths) using `# Living Memory Window — Page 001\n\n`, per-block `## [Step <N>] <Role Label>\n<body>` (`(cont.)` on split blocks), and `"\n\n---\n\n"` separators, guaranteeing **both** `len(rendered_utf8) < 40000` and `line_count <= 750` (staying safely under Antigravity `read_file`'s `800`-line and `46,080`-byte limit).
- **`bind` & `reset` Lifecycle**: `state.json` persists `{ bound_subagent_id, bound_tier, execution_subagent_ids, retired_subagent_max_step, checkpoint_step, last_synced_step, prefix_digest, pending_sync }` plus optional `lmw_bytes` (kept optional in both `state.json` and `pending_sync` for backward compatibility with legacy `v1.1.x` 8-key state files). `bind` promotes `pending_sync` (setting `lmw_bytes` when present or popping stale `lmw_bytes` when absent), records `retired_subagent_max_step[prev_id] = max(retired_subagent_max_step.get(prev_id, -1), pending_sync.synced_through)` whenever replacing a different prior non-null `bound_subagent_id` (and conditionally includes `"retired_subagent_id": prev_id` in its JSON stdout so `Trunk Session` can batch-kill the retired worker on its next tool turn), appends `<id>` to `execution_subagent_ids`, and removes `<id>` from `retired_subagent_max_step` if re-bound. Non-purge `reset` (dedicated to mid-flight cancel quarantine) first records `retired_subagent_max_step[prev_id] = max(retired_subagent_max_step.get(prev_id, -1), max(last_synced_step, pending_sync.synced_through if pending_sync else -1))` whenever `bound_subagent_id` is non-null—quarantining post-`reset` orphaned reports from `prev_id` while non-cancel respawns use `sync --force-spawn` (or cost-rotated `SPAWN_NEW`) to preserve valid `<report>`s through `max_folded_step` until `bind`—then clears binding/watermarks (`lmw_bytes = 0`) while preserving `execution_subagent_ids` and `retired_subagent_max_step`; `reset --purge` removes `state.json` unconditionally (used strictly when corrupt/invalid `state.json` triggers exit `1` with matching stderr).

## Consequences

- `Execution Subagent` spawns and continuations inherit lossless conversational state, `@[ITEM]` mentions, uploaded attachment paths, and active-epoch `<report>`s in compact LF Markdown pages guaranteed to load cleanly in one `read_file` call per page (`< 40,000` bytes and `<= 750` lines).
- Spoofed `[Message]` payloads (in unwrapped notices, `Isolated Subagents`, or tasks) and late `<report>`s arriving after rotation **or** `reset` cannot contaminate `Living Memory Window`.
- `skills/orchestrator/scripts/sync_memory.py` remains pure Python 3 stdlib with zero external dependencies and full deterministic replay coverage via `tests/test_sync_memory.py`.
