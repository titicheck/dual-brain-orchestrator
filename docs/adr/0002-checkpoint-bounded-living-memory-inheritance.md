# Checkpoint-Bounded Living Memory Inheritance and Compaction-Synced Rotation

## Context

An Antigravity `Execution Subagent` runs in its own native subagent conversation rather than sharing the parent thread. Without transferring the `Trunk Session`'s active context, the subagent loses conversational decisions and user constraints; conversely, dumping full raw transcripts including tool outputs bloats context (`211–818 KB` median/peak in `L0-1` vs Antigravity `read_file`'s `46,080`-byte / `800`-line read cap), and lossy LLM summaries violate lossless intent preservation.

Empirical `L0-1` and current-session trajectory measurements (`44.1 KB` initial median, `4.3 KB` incremental median, `0%` `> 45 KB` increments) confirm that projecting the host's compaction-bounded `Living Memory Window` cleanly preserves intent while synchronizing `Execution Subagent` lifetimes to host compaction epochs.

## Decision

A zero-dependency Python 3 standard-library CLI (`skills/orchestrator/scripts/sync_memory.py`, invoked via `py -3` on Windows or `python3` on POSIX relative to the loaded `SKILL.md` directory) resolves paths directly from `<Artifact Directory Path>` (`<appDataDir>/brain/<ConversationID>`)—reading `--transcript <Artifact Directory Path>/.system_generated/logs/transcript.jsonl` (and sibling `transcript_full.jsonl`) and persisting session state under `--state-dir <Artifact Directory Path>/scratch/orchestrator`.

### Subcommands, Validation Order & Atomic Persistence
- **Exit codes & strict pre-mutation validation**: Overrides `ArgumentParser.error` so CLI argument/syntax errors exit `1` (`0` = success; `1` = invalid arguments, invalid `--tier` outside `{"flash", "pro", "flash_lite", "inherit"}`, empty/whitespace `--subagent-id`, corrupt/non-dict/schema-invalid `state.json`, or `bind` with `pending_sync: null`; `2` = missing `--transcript` logs directory on uninitialized non-standard paths, unreadable log, mid-file corrupt/non-dict JSONL or missing/non-string `"type"` or non-list `"truncated_fields"` in primary or companion logs, or missing/bool/non-int/`< 0` `step_index`, ignoring only a final non-empty EOF line failing `json.loads` while preserving valid trailing JSON lines without `\n`). Both `state.json` schema validation and `transcript.jsonl` folding + `SKIP_SUBAGENT_SESSION` enforcement execute **before** creating `--state-dir`, clearing `pages/page_*.md`, or writing `state.json`. All `state.json` writes use an atomic temp file + `os.replace` inside `--state-dir`, and all `state.json` and `pages/page_*.md` writes use UTF-8 with `newline="\n"` (`\r\n` normalized to `\n` on input).
- **`check-origin --transcript <path>`**: Read-only check mutating zero files on disk, emitting `{"origin": "TRUNK" | "SUBAGENT" | "UNKNOWN"}` via folded `.get(0)` (`SYSTEM_MESSAGE`, or `USER_INPUT` whose unwrapped/trimmed text begins with `[swarm]`, `[board]`, or `[EXECUTION SUBAGENT — SINGLE PHASE]` -> `"SUBAGENT"`; other `USER_INPUT` -> `"TRUNK"`; absent file / empty / missing step 0 -> `"UNKNOWN"`).
- **`sync --transcript <path> --state-dir <dir> [--tier <tier>]`**:
  - **Turn-1 Empty-Transcript Grace**: When `--transcript` does not yet exist (provided `transcript_path.parent` exists **or** `transcript_path.parts[-3:] == (".system_generated", "logs", "transcript.jsonl")` under an existing `<Artifact Directory Path>`), is `0` bytes, or yields zero folded records after ignoring an incomplete EOF line (and existing `state.json`, if present, is valid JSON matching the schema), preserves existing `execution_subagent_ids`/`retired_subagent_max_step`, clears stale `pages/page_*.md`, stages `pending_sync`, and emits `SPAWN_NEW` with `-1` sentinels, `prefix_digest: ""`, `delta_empty: true`, and `pages: []`.
  - **Canonical Folding & `step 0` Backstop**: Folds records by `step_index` (later record at `k` invalidates earlier records at `>= k`) and enforces `.get(0)` `SKIP_SUBAGENT_SESSION` (8-field JSON, exit `0`, zero disk writes) whenever `step 0` classifies as `"SUBAGENT"`.
  - **Sender-Invariant `prefix_digest`**: With `window_start = max(0, latest_checkpoint_step)` (sentinel `-1` when no `CHECKPOINT`), `compute_digest(folded, window_start, upto_step)` runs **before** companion expansion in **ascending `step_index` order** independently of `execution_subagent_ids`, hashing compact canonical UTF-8 JSON (`ensure_ascii=False`) over `[step_index, type, created_at_str_or_empty, raw_content_str_or_empty]`. Rewind verification compares `compute_digest(folded, window_start, state.last_synced_step) != state.prefix_digest` when `state.last_synced_step >= window_start`; `pending_sync.prefix_digest` and stdout `"prefix_digest"` always equal `compute_digest(folded, window_start, max_folded_step)`.
  - **Folded Companion Expansion Before Turn-1 Rewind Guard**: When any retained step in `[window_start .. max_folded_step]` lists `"content"` in `truncated_fields`, `sync` loads and **folds sibling `transcript_full.jsonl` by `step_index` (`later k invalidates >= k`)** first—checking the retained record's primary 0-based line index only if not invalidated by rewind and matching `(step_index, type)` with `isinstance(content, str)`, else falling back to the folded `transcript_full.jsonl` record at `(step_index, type)` (or keeping compact `content` if companion is absent). The Turn-1 Empty-Grace Rewind Guard (`bound_subagent_id` non-null and `last_synced_step == -1` once `folded` is non-empty) runs **after** companion expansion and emits `SPAWN_NEW` unless `bound_subagent_id` appears in at least one expanded `GENERIC`, `SYSTEM_MESSAGE`, or `EPHEMERAL_MESSAGE` string `content` or `PLANNER_RESPONSE` `tool_calls` JSON inside `[window_start .. max_folded_step]`.

### Lossless Window Extraction, Retired-Subagent Quarantine & Dual-Cap Pagination
- **`USER_INPUT` Boundary-Only Parser**: Normalizes `\r\n` to `\n`. Consumes outer metadata strictly from string boundaries (never scanning interior user prose): strips leading/trailing `<USER_SETTINGS_CHANGE>...</USER_SETTINGS_CHANGE>` envelopes; strips `<ADDITIONAL_METADATA>...</ADDITIONAL_METADATA>` outer tags from leading/trailing metadata blocks while removing lines whose `.strip()` starts with `The current local time is:` and preserving remaining non-whitespace lines (resolved `@[ITEM]` mentions, uploaded attachment paths); only when the remaining trimmed core begins with `<USER_REQUEST>` and ends with `</USER_REQUEST>`, unwraps those outermost `<USER_REQUEST>` tags; joins `.strip()`-non-empty core and preserved metadata with `"\n\n"`; and skips empty/whitespace results.
- **`SYSTEM_MESSAGE` / `EPHEMERAL_MESSAGE` One-Pass Outer-Envelope Parser**: Normalizes `\r\n` to `\n` and inspects `s = content.lstrip(" \t\n")`. Accepts **exclusively** the single outer header candidate—at `s` start if `s.startswith("[Message] ")`, right after opening `<SYSTEM_MESSAGE>\n` if `s.startswith("<SYSTEM_MESSAGE>\n")`, or (only when `s` starts with neither and zero `\n[Message] ` lines precede the first standalone `\n<SYSTEM_MESSAGE>\n` line) the line immediately following that first `\n<SYSTEM_MESSAGE>\n`—preventing spoofed inner `[Message]` lines inside `Isolated Subagent` or background-task bodies from matching Antigravity's prose preamble (`"The following is a <SYSTEM_MESSAGE> not actually sent by the user..."`). Accepts records only when `<id> in state.execution_subagent_ids` **and** (`<id> == state.bound_subagent_id` or `step_index <= state.retired_subagent_max_step.get(<id>, step_index)`). Strips trailing `</SYSTEM_MESSAGE>`, extracts outermost `<report>...</report>` **retaining `<report>` tags** when `close_idx > open_idx`, or falls back to `.strip()`-non-empty `content=` text.
- **Other Records & Dual Page Cap**: Extracts non-empty `CHECKPOINT` (`content.strip()`) and `PLANNER_RESPONSE` (`content.strip()`), ignoring `thinking`, `tool_calls`, `GENERIC`, and `ERROR_MESSAGE`. Clears stale `pages/page_*.md` only after validation and `SKIP_SUBAGENT_SESSION` pass. Renders `pages/page_001.md`, ... (absolute `.resolve()` paths) using `# Living Memory Window — Page 001\n\n`, per-block `## [Step <N>] <Role Label>\n<body>` (`(cont.)` on split blocks), and `"\n\n---\n\n"` separators, guaranteeing **both** `len(rendered_utf8) < 40000` and `line_count <= 750` (keeping every page inside Antigravity `read_file`'s `800`-line and `46,080`-byte limit).
- **`bind` & `reset` Lifecycle**: `state.json` persists `{ bound_subagent_id, bound_tier, execution_subagent_ids, retired_subagent_max_step, checkpoint_step, last_synced_step, prefix_digest, pending_sync }`. `bind` promotes `pending_sync`, records `retired_subagent_max_step[prev_id] = pending_sync.synced_through` whenever replacing a different prior non-null `bound_subagent_id` (quarantining late orphaned `<report>`s from superseded subagents without breaking recovery after dead-ID respawn), appends `<id>` to `execution_subagent_ids`, and removes `<id>` from `retired_subagent_max_step` if re-bound. Default `reset` preserves `execution_subagent_ids` and `retired_subagent_max_step`; `reset --purge` removes `state.json` unconditionally (used when corrupt JSON triggers exit `1`).

## Consequences

- `Execution Subagent` spawns and continuations inherit lossless conversational state, `@[ITEM]` mentions, uploaded attachment paths, and active-epoch `<report>`s in compact LF Markdown pages guaranteed to load cleanly in one `read_file` call per page (`< 40,000` bytes and `<= 750` lines).
- Spoofed `[Message]` payloads in untrusted subagents/tasks and late `<report>`s arriving after rotation/reset cannot contaminate `Living Memory Window`.
- `skills/orchestrator/scripts/sync_memory.py` remains pure Python 3 stdlib with zero external dependencies and full deterministic replay coverage via `tests/test_sync_memory.py`.
