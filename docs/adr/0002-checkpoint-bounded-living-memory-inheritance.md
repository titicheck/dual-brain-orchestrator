# Checkpoint-Bounded Living Memory Inheritance and Compaction-Synced Rotation

To give an Antigravity `Execution Subagent` the same living context as Official Orchestrator's shared-thread execution model without unbounded transcript growth or lossy manual summaries, a zero-dependency Python 3 standard-library CLI (`skills/orchestrator/scripts/sync_memory.py`, invoked via `py -3` on Windows or `python3` on POSIX relative to `SKILL.md`) resolves paths directly from `<Artifact Directory Path>` (`<appDataDir>/brain/<ConversationID>`)—reading `--transcript <Artifact Directory Path>/.system_generated/logs/transcript.jsonl` and writing session state into `--state-dir <Artifact Directory Path>/scratch/orchestrator`. CLI argument parsing overrides `ArgumentParser.error` to exit `1` (`0` = success, `1` = invalid arguments/tiers, empty `--subagent-id`, invalid JSON state, or `bind` when `pending_sync` is `null`, `2` = missing conversation logs parent directory, unreadable log, mid-file corrupt JSONL, or missing non-boolean integer `step_index`, ignoring only an incomplete final non-empty EOF line). It exposes four subcommands: `check-origin --transcript <path>` (read-only inspection mutating zero files on disk, emitting `{"origin": "TRUNK" | "SUBAGENT" | "UNKNOWN"}` from folded `step 0` `USER_INPUT` vs `SYSTEM_MESSAGE`, used by post-compaction Gate 3 checks), `sync --transcript <path> --state-dir <dir> [--tier <tier>]` (validating `--tier` against `{"flash", "pro", "flash_lite", "inherit"}`), `bind --state-dir <dir> --subagent-id <non_empty_id>`, and `reset --state-dir <dir> [--purge]`. On Turn 1 if the logs directory exists while `--transcript` does not yet exist or is 0 bytes, `sync` clears stale `pages/` and stages `pending_sync` in `state.json`, emitting `{"action": "SPAWN_NEW", "tier": tier, "subagent_id": null, "checkpoint_step": -1, "synced_through": -1, "prefix_digest": "", "delta_empty": true, "pages": []}` so `bind` succeeds. Otherwise `sync` folds append-only records by canonical non-boolean integer `step_index` (later record at `k` invalidates earlier records at `>= k`), enforcing a hard backstop returning `{"action": "SKIP_SUBAGENT_SESSION", ...}` with exit `0` and zero state mutation whenever folded `step 0` has `type == "SYSTEM_MESSAGE"`. Using `window_start = max(0, latest_checkpoint_step)` (`-1` no-checkpoint sentinel), `prefix_digest` is computed **before** `transcript_full.jsonl` expansion and **independently of `execution_subagent_ids`** across `[window_start .. last_synced_step]` as `sha256` hex of `json.dumps([[r["step_index"], r["type"], r.get("created_at", ""), r.get("content") if isinstance(r.get("content"), str) else ""] for r in folded_records if window_start <= r["step_index"] <= last_synced_step], separators=(",", ":"), ensure_ascii=False)`, short-circuiting to `""` when `last_synced_step < window_start` (eliminating false post-compaction/post-rewind digest mismatches). Retained steps within `[window_start .. max_folded_step]` whose `"truncated_fields"` includes `"content"` expand from fixed sibling `transcript_full.jsonl` (verifying `(step_index, type)` equality at the 0-based line index first, then matching last `(step_index, type)`, ignoring incomplete companion EOF lines and falling back gracefully to compact `content` if `transcript_full.jsonl` is absent). Within `[window_start .. max_folded_step]`, `sync` extracts `CHECKPOINT` `content`; `USER_INPUT` unwrapped first at outermost `<USER_REQUEST>...</USER_REQUEST>` (stripping outer sibling `<ADDITIONAL_METADATA>` and `<USER_SETTINGS_CHANGE>`, skipping whitespace-only text); non-empty `PLANNER_RESPONSE` string `content` (`content.strip()`, omitting `thinking`, `tool_calls`, `GENERIC`, `ERROR_MESSAGE`); and `<report>...</report>` from `SYSTEM_MESSAGE`/`EPHEMERAL_MESSAGE` anchored on the outer `[Message] timestamp=... sender=<id>` header line (after optional `<SYSTEM_MESSAGE>` preamble) **only** when `<id> in state.execution_subagent_ids` (matching outermost `<report>...</report>`, falling back to the outer `[Message]` body if `<report>` tags were omitted). Before rendering pages, stale `<state-dir>/pages/page_*.md` files are cleared and sequential Markdown pages (`# Living Memory Window — Page 001` fixed-width total-page-independent headers) are written strictly `< 40,000` UTF-8 bytes including headers and separators (`len(rendered.encode("utf-8")) < 40000`). `<state-dir>/state.json` persists `{ bound_subagent_id, bound_tier, execution_subagent_ids, checkpoint_step, last_synced_step, prefix_digest, pending_sync }`, where `execution_subagent_ids` is an **append-only allowlist** of bound subagents across the conversation. Both `SPAWN_NEW` (`bound_subagent_id` `null`, `latest_checkpoint_step != checkpoint_step`, `max_folded_step < last_synced_step`, `prefix_digest` mismatch, or `tier != bound_tier`) and `RESUME_EXISTING` use **symmetric two-phase commit** via `pending_sync`: `bind` promotes `pending_sync` after `invoke_subagent` or `send_message` succeeds and appends `<id>` to `execution_subagent_ids` if absent; default `reset` clears active watermarks (`bound_subagent_id: null`, `bound_tier: "flash"`, `checkpoint_step: -1`, `last_synced_step: -1`, `prefix_digest: ""`, `pending_sync: null`, and `pages/`) **while preserving `execution_subagent_ids`** so recovery never drops prior active-epoch `<report>`s (only `reset --purge` deletes `state.json` completely). Empirical `L0-1` measurements (`44.1 KB` initial median, `4.3 KB` incremental median, `0%` `>45 KB` increments vs `211–818 KB` raw-tool bloat) confirm full intent preservation with compaction-synced rotation.
