# Checkpoint-Bounded Living Memory Inheritance and Compaction-Synced Rotation

To give a cross-session native subagent the same living context as Official Orchestrator's shared-thread execution model without unbounded transcript growth or lossy manual summaries, a local zero-LLM Python 3 standard-library CLI (`skills/orchestrator/scripts/sync_memory.py`) will fold Antigravity's `transcript.jsonl` by canonical `step_index` (resolving `transcript_full.jsonl` only when `"content"` is in `truncated_fields` on a retained step) into `<appDataDir>/brain/<ConversationID>/scratch/orchestrator/` and export the active `CHECKPOINT`-bounded **Living Memory Window** (`[latest CHECKPOINT (or Step 0) .. current_step]`), retaining `CHECKPOINT` compaction summaries, verbatim `USER_INPUT` `<USER_REQUEST>` text (stripped of `<ADDITIONAL_METADATA>` and `<USER_SETTINGS_CHANGE>`), visible `PLANNER_RESPONSE`/`MODEL` replies, and inbound `<report>...</report>` blocks while omitting `GENERIC` tool outputs, non-report system messages, and private `thinking`. Pages are cleared per sync and split on message, line, or valid UTF-8 code-point boundaries strictly below `40,000` bytes so every page fits one `46,080`-byte `read_file` call. `state.json` tracks `{ bound_subagent_id, bound_tier, checkpoint_step, last_synced_step, prefix_digest }`: `sync` emits `SPAWN_NEW` whenever `bound_subagent_id` is null, `latest_checkpoint_step != checkpoint_step`, `max_step < last_synced_step`, `prefix_digest` changes under turn rewind/edit, or `requested_tier != bound_tier` (committed via `bind` once `invoke_subagent` returns `conversationId`, with `reset` clearing dead subagents), and otherwise advances watermarks directly in a single `RESUME_EXISTING` call exporting `(last_synced_step, current_step]`. Non-Antigravity harnesses without `transcript.jsonl` never synthesize LLM-written history pages—relying directly on a self-contained `<plan>` plus native stateful continuation (`resume` / `followup_task`). Empirical `L0-1` measurements (`44.1 KB` initial median, `4.3 KB` incremental median, `0%` `>45 KB` increments vs `211–818 KB` raw-tool bloat) confirm full intent preservation with automatic compaction-synced lifecycle rotation.
