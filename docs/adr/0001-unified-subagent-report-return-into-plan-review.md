# Unified Subagent Report Return into Official Plan Review

Because a native subagent cannot address the human user directly (`send_message` and subagent completion messages always return to the parent conversation), we will unify Official Orchestrator's two inbound paths—direct execution-to-user completion on short runs and `enter_plan_mode(reason)` hand-backs—into a single return path: on every exit (full verified completion, ~30-step cadence checkpoint, or any of the five early hand-back triggers), the subagent replies to the main session with Official Orchestrator's standard execution `<report>` (what was done, what verifications ran and showed, any repeated failures or out-of-plan needs, and what remains). The main session handles every return through Official Orchestrator's unmodified three-way `[plan review]` gate (dispatch remaining steps, dispatch a revised plan stating what to undo / do instead / verify, or report verified completion to the user and stop), introducing zero custom receipt or error-dump files while reading the host's native subagent `logAbsoluteUri` on demand whenever raw step output is needed.
