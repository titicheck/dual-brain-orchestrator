# Matt-Aligned Pure-Skill Plugin Packaging, Antigravity-First Scope, and Unified Tier Lock

To preserve clean user control, decouple manual invocation from global automatic orchestration, and focus V1 optimization strictly on Antigravity while reserving a clean cross-harness extension seam, we reject bundling plugin-root `rules/AGENTS.md` (which Antigravity's plugin switch merges and unloads atomically alongside bundled skills) and omit unverified `rule-adoption.md` `<24,000`-byte contract artifacts as well as Codex-specific V1 manifests (`skills/orchestrator/agents/openai.yaml`, `.codex-plugin/plugin.json`). Under unified identifier `orchestrator`, we ship a Matt-aligned pure-skill repository layout with zero top-level `rules/` directory, zero `hooks.json`, and zero persistent sidecars: `plugin.json` (`{"name": "orchestrator", "version": "1.0.0", "description": "...", "skills": ["./skills/orchestrator"]}`), `.claude-plugin/plugin.json` (`{"name": "orchestrator", "version": "1.0.0", "description": "...", "skills": ["./skills/orchestrator"]}`), `.claude-plugin/marketplace.json` (`{"name": "orchestrator", "owner": {"name": "orchestrator"}, "description": "...", "plugins": [{"name": "orchestrator", "source": "./", "description": "..."}]}`), `README.md` (including install guidance plus a concise `<=1 KB` copyable Antigravity `AGENTS.md` / shared-engineering-library table row and inline rule snippet), `skills/orchestrator/{SKILL.md, scripts/sync_memory.py, references/{execution-protocol.md, harnesses.md}}` (where `references/harnesses.md` fully specifies Antigravity and defines a modular Harness Adapter Interface with non-normative reserved stubs for Claude Code and Codex), and standard-library Python `unittest` suites `tests/{test_sync_memory.py, test_package_contracts.py, fixtures/}`. `SKILL.md` omits `disable-model-invocation: true` so shared or workspace `AGENTS.md` rules can load the skill on Antigravity, restricts its frontmatter `description` strictly to literal `/orchestrator` invocation or explicit active `AGENTS.md` rule adoption (explicitly omitting `"or names orchestrator"`), and enforces **Entry Gate #0** (immediately aborting if neither literal `/orchestrator` nor an active Antigravity rule-adoption directive authorized the load). Across both rule-adopted and manual invocations, **one uniform tier rule** governs Antigravity execution: `Execution Subagent` defaults to and locks at `Model: "flash"` (ignoring conversational model mentions), permitting `"pro"`, `"flash_lite"`, or `"inherit"` **only** when explicitly passed via `/orchestrator <tier>` on that user request—preserving that override across internal `[plan review]` continuations of that request and resetting automatically to `"flash"` on the next new user message.
